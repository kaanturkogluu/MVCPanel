Migration Nedir ?

panel/models/migration/

klasörü içerisinde bulunur .


Migration veri tabanı tablolarını kod üzerinde oluşturduğumuz alan .

Bu sayede sistem yeni bir alana aktarıldığında sqldumpa ihtiyaç duyulmadan tüm tablolar sorunsuz ve eksiksiz şekilde yeni sisteme aktarılır

Migration temel yapı tasını BluePrint classı oluşturmakta, blueprint kullanarak genel bir taslak üzerinden tablo yapımızı oluştracağız.

Bunun için

panel/models/migration/migrations.php

dosyası üzerinde blueprint kodlarımızı yazacağız

BluePrint İçeriği

İçerisinde tablo stunları oluşturmak için kullanılacak olan fonksiyonlar mevcuttur .

Fonksiyonların tamamı basit ve kullanışlı.

Yeni Tablo oluşturmak için öncellikle

migrations.php dosyası içerisine girip yeni nesne olusturacaz

Constructor metodundan dolayı nesne oluşturulurken tablo ismimiz parametre olarak gönderilecektir.

Daha sonra oluşturulan nesne üzerinden tablo stunları ayarlanacaktır.


PHP 
$userBlueprint = new Blueprint('ac_users');
$userBlueprint->id() 
->string('username')
->unique()
->string('password')
->string('user_token')
->timestamp('last_login')
->timestamps();

base model fonksiyonlar


PHP 
// Tüm kullanıcıları getir
$users = $userModel->all();

// ID'ye göre kullanıcı getir
$user = $userModel->find(1);

// Email'e göre kullanıcı getir
$user = $userModel->findBy('email', 'user@example.com');

// Yeni kullanıcı ekle
$userId = $userModel->create([
    'name' => 'John Doe',
    'email' => 'john@example.com'
]);

// Kullanıcı güncelle
$userModel->update(1, [
    'name' => 'Jane Doe'
]);

// Kullanıcı sil
$userModel->delete(1);

// Sayfalama ile kullanıcıları getir
$users = $userModel->paginate(1, 10);

// Where koşulları ile kullanıcıları getir
$activeUsers = $userModel
    ->where('status', 'active')
    ->orderBy('created_at', 'DESC')
    ->all();

ac_users Tablosu



SQL 
CREATE TABLE `ac_users` (
  `id` int(11) NOT NULL AUTO_INCREMENT,
  `username` varchar(50) NOT NULL,
  `password` varchar(255) NOT NULL,
  `email` varchar(100) NOT NULL,
  `full_name` varchar(100) DEFAULT NULL,
  `user_token` varchar(255) DEFAULT NULL,
  `status` tinyint(1) DEFAULT 1,
  `last_login` datetime DEFAULT NULL,
  `created_at` datetime DEFAULT CURRENT_TIMESTAMP,
  `updated_at` datetime DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  UNIQUE KEY `username` (`username`),
  UNIQUE KEY `email` (`email`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
