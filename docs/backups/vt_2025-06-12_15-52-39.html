Veritabanı Dokümantasyonu

Bu dokümantasyon, panel sisteminin veritabanı yapısını ve tablolarını detaylı bir şekilde açıklamaktadır. Sistem, MySQL veritabanı kullanmaktadır ve aşağıdaki tablolardan oluşmaktadır:

  • ac_users: Kullanıcı bilgileri ve kimlik doğrulama
  • ac_settings: Sistem ayarları
  • ac_logs: Sistem logları
  • ac_permissions: İzin tanımlamaları
  • ac_roles: Rol tanımlamaları
  • ac_user_roles: Kullanıcı-rol ilişkileri

Tablolar

Sistemde bulunan tüm tablolar ve kısa açıklamaları:

Tablo Adı Açıklama İlişkili Tablolar
ac_users Kullanıcı hesapları ve kimlik bilgileri ac_user_roles, ac_logs
ac_settings Sistem genel ayarları -
ac_logs Sistem aktivite kayıtları ac_users
ac_permissions İzin tanımlamaları ac_roles
ac_roles Rol tanımlamaları ac_permissions, ac_user_roles
ac_user_roles Kullanıcı-rol eşleştirmeleri ac_users, ac_roles

ac_users Tablosu

Kullanıcı hesaplarının tutulduğu ana tablo. Kullanıcı kimlik bilgileri, profil bilgileri ve hesap durumu burada saklanır.

SQL 
CREATE TABLE `ac_users` (
  `id` int(11) NOT NULL AUTO_INCREMENT,
  `username` varchar(50) NOT NULL,
  `password` varchar(255) NOT NULL,
  `email` varchar(100) NOT NULL,
  `full_name` varchar(100) DEFAULT NULL,
  `user_token` varchar(255) DEFAULT NULL,
  `status` tinyint(1) DEFAULT 1,
  `last_login` datetime DEFAULT NULL,
  `created_at` datetime DEFAULT CURRENT_TIMESTAMP,
  `updated_at` datetime DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  UNIQUE KEY `username` (`username`),
  UNIQUE KEY `email` (`email`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

Alan Açıklamaları

Alan Tip Açıklama
id int(11) Otomatik artan benzersiz kimlik
username varchar(50) Benzersiz kullanıcı adı
password varchar(255) Şifrelenmiş parola
email varchar(100) Benzersiz e-posta adresi
full_name varchar(100) Kullanıcının tam adı
user_token varchar(255) Oturum ve API token'ı
status tinyint(1) Hesap durumu (1: aktif, 0: pasif)
last_login datetime Son giriş tarihi
created_at datetime Kayıt oluşturma tarihi
updated_at datetime Son güncelleme tarihi

ac_settings Tablosu

Sistem genel ayarlarının tutulduğu tablo. Tüm sistem ayarları key-value yapısında saklanır.

SQL 
CREATE TABLE `ac_settings` (
  `id` int(11) NOT NULL AUTO_INCREMENT,
  `setting_key` varchar(50) NOT NULL,
  `setting_value` text DEFAULT NULL,
  `setting_group` varchar(50) DEFAULT 'general',
  `description` varchar(255) DEFAULT NULL,
  `created_at` datetime DEFAULT CURRENT_TIMESTAMP,
  `updated_at` datetime DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  UNIQUE KEY `setting_key` (`setting_key`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

Alan Açıklamaları

Alan Tip Açıklama
id int(11) Otomatik artan benzersiz kimlik
setting_key varchar(50) Benzersiz ayar anahtarı
setting_value text Ayar değeri
setting_group varchar(50) Ayar grubu (varsayılan: general)
description varchar(255) Ayar açıklaması
created_at datetime Kayıt oluşturma tarihi
updated_at datetime Son güncelleme tarihi

ac_logs Tablosu

Sistem aktivite kayıtlarının tutulduğu tablo. Tüm kullanıcı işlemleri ve sistem olayları burada loglanır.

SQL 
CREATE TABLE `ac_logs` (
  `id` int(11) NOT NULL AUTO_INCREMENT,
  `user_id` int(11) DEFAULT NULL,
  `action` varchar(50) NOT NULL,
  `description` text DEFAULT NULL,
  `ip_address` varchar(45) DEFAULT NULL,
  `user_agent` text DEFAULT NULL,
  `created_at` datetime DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  KEY `user_id` (`user_id`),
  CONSTRAINT `ac_logs_ibfk_1` FOREIGN KEY (`user_id`) REFERENCES `ac_users` (`id`) ON DELETE SET NULL
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

Alan Açıklamaları

Alan Tip Açıklama
id int(11) Otomatik artan benzersiz kimlik
user_id int(11) İşlemi yapan kullanıcı ID'si (ac_users tablosu ile ilişkili)
action varchar(50) Yapılan işlem türü
description text İşlem açıklaması
ip_address varchar(45) İşlemin yapıldığı IP adresi
user_agent text Kullanıcı tarayıcı bilgisi
created_at datetime Log kaydı oluşturma tarihi

ac_permissions Tablosu

Sistem izinlerinin tanımlandığı tablo. Her bir izin benzersiz bir anahtar ile tanımlanır.

SQL 
CREATE TABLE `ac_permissions` (
  `id` int(11) NOT NULL AUTO_INCREMENT,
  `permission_key` varchar(50) NOT NULL,
  `permission_name` varchar(100) NOT NULL,
  `description` text DEFAULT NULL,
  `created_at` datetime DEFAULT CURRENT_TIMESTAMP,
  `updated_at` datetime DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  UNIQUE KEY `permission_key` (`permission_key`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

Alan Açıklamaları

Alan Tip Açıklama
id int(11) Otomatik artan benzersiz kimlik
permission_key varchar(50) Benzersiz izin anahtarı
permission_name varchar(100) İzin adı
description text İzin açıklaması
created_at datetime Kayıt oluşturma tarihi
updated_at datetime Son güncelleme tarihi

ac_roles Tablosu

Kullanıcı rollerinin tanımlandığı tablo. Her rol bir dizi izne sahip olabilir.

SQL 
CREATE TABLE `ac_roles` (
  `id` int(11) NOT NULL AUTO_INCREMENT,
  `role_name` varchar(50) NOT NULL,
  `description` text DEFAULT NULL,
  `is_system` tinyint(1) DEFAULT 0,
  `created_at` datetime DEFAULT CURRENT_TIMESTAMP,
  `updated_at` datetime DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  UNIQUE KEY `role_name` (`role_name`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

Alan Açıklamaları

Alan Tip Açıklama
id int(11) Otomatik artan benzersiz kimlik
role_name varchar(50) Benzersiz rol adı
description text Rol açıklaması
is_system tinyint(1) Sistem rolü mü? (1: evet, 0: hayır)
created_at datetime Kayıt oluşturma tarihi
updated_at datetime Son güncelleme tarihi

ac_user_roles Tablosu

Kullanıcıların rollerle eşleştirildiği ara tablo. Bir kullanıcı birden fazla role sahip olabilir.

SQL 
CREATE TABLE `ac_user_roles` (
  `id` int(11) NOT NULL AUTO_INCREMENT,
  `user_id` int(11) NOT NULL,
  `role_id` int(11) NOT NULL,
  `created_at` datetime DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  UNIQUE KEY `user_role` (`user_id`,`role_id`),
  KEY `role_id` (`role_id`),
  CONSTRAINT `ac_user_roles_ibfk_1` FOREIGN KEY (`user_id`) REFERENCES `ac_users` (`id`) ON DELETE CASCADE,
  CONSTRAINT `ac_user_roles_ibfk_2` FOREIGN KEY (`role_id`) REFERENCES `ac_roles` (`id`) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

Alan Açıklamaları

Alan Tip Açıklama
id int(11) Otomatik artan benzersiz kimlik
user_id int(11) Kullanıcı ID'si (ac_users tablosu ile ilişkili)
role_id int(11) Rol ID'si (ac_roles tablosu ile ilişkili)
created_at datetime Kayıt oluşturma tarihi
